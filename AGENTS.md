# Editing HannaLaikin.com

This repository is the source of truth for HannaLaikin.com.

## Identity
Hanna Laikin is:
- Co-Founder & Head of Product at NOCI
- Founder of BrightPoint Communications
- Creator & Host of The Hustle by Hanna

## Editing rules
- Preserve a premium editorial fashion/tech aesthetic.
- Keep the site fast, static, mobile-first, and accessible.
- Do not remove SEO metadata, Person schema, canonical URLs, sitemap, robots.txt, or CNAME.
- Make edits directly to the source files in this repo.
- Pushing to `main` automatically deploys the site through GitHub Pages.
- Keep `hannalaikin.com` as the canonical domain.

## Main files
- `index.html` — homepage
- `media.html` — media kit
- `styles.css` — visual system
- `script.js` — light client-side behavior
